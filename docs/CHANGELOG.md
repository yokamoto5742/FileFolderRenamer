# 変更履歴

このプロジェクトの主な変更は、このファイルに記録されています。

フォーマットは [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) に基づいており、
このプロジェクトは [Semantic Versioning](https://semver.org/lang/ja/) に従っています。

## [Unreleased]

### 追加

- `[Watch1]`, `[Watch2]`... の連番セクションで複数の監視元ディレクトリを設定できる機能（単一の `Observer` にまとめて登録）
- 監視元ディレクトリごとにリネームパターンを切り替える機能（パターンは各 `[WatchN]` セクション内に記述）
- アプリケーション起動時に監視対象ディレクトリ内に既に存在するファイルを処理する機能
- 監視元ディレクトリが重複して設定された場合に警告ログを出してスキップする処理

### 変更

- **破壊的変更**: 設定ファイルの `[Paths]` / `[Rename]` セクションを廃止し、`[WatchN]` セクションに移行
- `config_manager` の `get_src_dir()` / `get_rename_patterns()` を `get_watch_targets()` / `compile_patterns()` に置き換え
- `FileRenameHandler` はパターンと待機時間をコンストラクタ引数で受け取るよう変更
- タスクトレイメニューの表示を監視対象の件数に変更し、「監視フォルダを開く」をサブメニュー化

## [1.0.0] - 2025-12-24

### 追加

- ファイルパスの型ヒント（`bytes | str`）を追加
- エッジケースのテストケースを追加
- ログ設定とクリーンアップ機能の型ヒントを追加

### 変更

- 設定値取得時にNoneチェックを明示的に実施
- ログローテーション設定値取得時にNoneチェックとデフォルト値を明確化
